## 📌 نظرة عامة | Overview

**Ashion Dashboard** هي لوحة تحكم إدارية متكاملة مخصصة لإدارة متجر الملابس **Ashion**. تتيح للمسؤولين إدارة المنتجات والمستخدمين بكل سهولة وكفاءة من خلال واجهة مستخدم سلسة واحترافية.

> A full-featured admin dashboard for managing the Ashion clothing store — products, users, and more.

---

## ✨ المميزات | Features

### 🧥 إدارة المنتجات | Product Management
- 📋 **عرض جميع المنتجات** — استعراض كامل لكتالوج الملابس
- ✏️ **تعديل المنتجات** — تحديث الاسم، السعر، الوصف، والصورة
- 🗑️ **حذف المنتجات** — إزالة المنتجات غير المتاحة

### 👥 إدارة المستخدمين | User Management
- 👤 **عرض المستخدمين** — قائمة بجميع المسجلين في المتجر
- 🔍 **بيانات تفصيلية** — الاطلاع على معلومات كل مستخدم

## 🚀 تشغيل المشروع | Getting Started

### المتطلبات | Prerequisites

```bash
node >= 16.x
npm >= 8.x
```

### خطوات التثبيت | Installation

```bash
# 1. استنساخ المستودع
git clone https://github.com/Abdullah-m-sh100/ashion-dashboard.git

# 2. الدخول إلى مجلد المشروع
cd ashion-dashboard

# 3. تثبيت المكتبات
npm install

# 4. تشغيل المشروع
npm start
```

ثم افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
